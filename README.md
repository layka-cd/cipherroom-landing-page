
# CipherRoom Landing Page

Landing page resmi CipherRoom, sebuah platform komunikasi privat dengan konsep keamanan dan privasi digital.

## 🌐 Live Demo

[https://chiperroom.layka.my.id/](https://chiperroom.layka.my.id/)

## ✨ Features

- Responsive landing page
- Neumorphism UI design
- Light and Dark Mode
- Smooth scrolling navigation
- Security and encryption information
- Modern and minimalist interface

## 🔐 Security Technologies

- AES-256-GCM
- PBKDF2-HMAC-SHA256
- Web Crypto API
- Zero-Knowledge Architecture

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Google Fonts
